# Topology coordinator demos

These recordings target live lab DRA clusters and are intended for
demonstration, not general-purpose deployment. Each demo README lists its
hardware and access prerequisites.

| Demo | Purpose |
|------|---------|
| [`topology-coordinator-dra-inspect`](topology-coordinator-dra-inspect/) | User-facing offering discovery and workload allocation |
| [`topology-coordinator-mig`](topology-coordinator-mig/) | User-facing NVIDIA MIG profile selection and NUMA placement |
| [`topology-coordinator-admin-debug`](topology-coordinator-admin-debug/) | Read-only configuration, catalog, DeviceClass, and DRA debugging |
| [`topology-coordinator-kubevirt`](topology-coordinator-kubevirt/) | KubeVirt passthrough allocation, topology alignment, counters, and VFIO verification |
